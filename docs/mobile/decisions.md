## Decisions still requiring an explicit product/architecture choice

1. **Native baseline:** minimum iOS, Xcode/Swift versions and package pins, chosen bundle ID and signing team. Masterplan suggests iOS18+; no requirement that unsupported entitlements be enabled. Foundation can build unsigned simulator first.
2. **Distribution/licensing:** standalone native repo license/AGPL compliance and App Store distribution terms need explicit review before copying AGPL platform implementation into a distributed binary; SDK Apache exception has not been granted to current code. No license change is made here.
3. **Staging:** operator/owner and isolated Supabase/worker/provider test registrations, accepted test data, exact proof of production migration state. Current local config is not evidence of hosted configuration.
4. **Revocation semantics:** is up to300s residual access acceptable for already issued signed URLs, or must read grants be actively revocable? How do max_uses, shared review feedback and ongoing playback relate? Cannot call the current implementation instantaneous.
5. **Cloud token lifetime:** refresh-token persistence versus explicit reconnect; provider account switching and Keychain background accessibility; native OAuth SDK choices.
6. **Import durability:** define acceptable full-retry size/cost and session recovery semantics before designing resumable worker protocol. Existing active-job dedup is insufficient as guaranteed idempotency.
7. **Concurrent drafts/releases:** explicit revision/merge policy and behavior of older web clients writing without revision. Atomic DB updates do not make provider-publicity changes atomic.
8. **Privacy/cache:** public disk snapshots versus encrypted owner-scoped private snapshots; default private memory-only. Offline audio is a separate future permissions/storage feature.
9. **Native push:** Apple capability/membership availability, APNs key custody/encryption, platform identifiers and device reassignment/logout contract. Android adapter remains future.
10. **Safety/public distribution:** Apple login alternative, real account deletion, reporting/blocking and moderation reachability. Do not silently infer compliance from the web UI or a contact email.

## Start conditions

The source baseline and portable tests allow **iOS0.1 Foundation** independently of production. Actual auth begins only with B0/B1 verification; robust imports/shares must resolve their gates before those milestones. [Ready-to-run prompt](ios-0.1-prompt.md) keeps these boundaries explicit.
