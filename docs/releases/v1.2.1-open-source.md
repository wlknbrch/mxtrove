# MxTrove 1.2.1: first open-source release

MxTrove is now available as an AGPL-3.0-only platform, copyright (C) 2026
Tom Maucksch. This source release includes the React frontend, media worker,
database migrations/RLS tests, and Docker build/deployment recipes.

## New for operators and contributors

- Contribution, support, conduct, security, and independent-fork branding rules.
- A self-hosting guide and generic Traefik Compose recipe with configurable
  domain, operator/contact, source offer, and optional cloud/push features.
- Source links across the app, shared releases/projects, embeds, and worker.
- Dependency notices, license files in web builds/containers, secret scanning,
  dependency monitoring, contribution sign-offs, and code scanning workflows.
- Compatible dependency security fixes and a pinned Node.js 22 development baseline.

Original music files remain in connected personal cloud accounts. Private
playback continues to require permission-checked derivatives. No real user
content, service credentials, or production database is part of this release.

## Install and contribute

Start with [self-hosting](../self-hosting.md) or [contributing](../../CONTRIBUTING.md).
Independent services should identify their operator and follow
[TRADEMARKS.md](../../TRADEMARKS.md). Future standalone SDKs may receive separate
Apache-2.0 licenses; there is no Apache exception for the current platform.

## Known limits

The frontend still has moderate React Router advisories; see
[the audit record](../security-audit.md). The S3 storage adapter is a placeholder.
Cloud OAuth needs each operator's own applications. UI demo mode is not a
working backend demonstration. This initial release publishes source/build
recipes, not prebuilt container images. Operators remain responsible for their
own terms/privacy practices, backups, costs, and provider restrictions.
