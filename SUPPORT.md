# Getting help

Use repository issues for reproducible bugs and concrete feature requests.
Read the [README](README.md) and [self-hosting guide](docs/self-hosting.md)
first. Include the version, relevant environment, and redacted logs.

Self-hosted instances are operated by their respective operators. Contact
your operator for account, privacy, moderation, or data-access requests.
The upstream project cannot access or recover data from another deployment.

For the official hosted service or project conduct matters, contact
mxtrove@wlknbrch.com. Report security problems privately using [SECURITY.md](SECURITY.md).
Support and feature requests have no guaranteed response time.
